# Typeface source

The OpenQuatt candidate identity uses **Inter**:

- “Open”: Inter SemiBold 600
- “Quatt”: Inter Bold 700
- UI and documentation: the Inter family with system sans-serif fallbacks

Maintainers can obtain Inter from the [official Inter project](https://rsms.me/inter/) or through the pinned `@fontsource/inter` development dependency in `brand/tools/package-lock.json`.

Inter is distributed upstream under the SIL Open Font License 1.1. Consult the upstream package for the authoritative license text.

No `.ttf`, `.otf`, `.woff` or `.woff2` file is redistributed in the OpenQuatt brand kit. Release logo SVGs contain only the necessary outlined glyph geometry.
